## 项目状态（2026-07-28 更新）

8 个状态，颜色独立：
未开始(灰) → UI确认(紫) → 开发中(蓝) → 测试中(琥珀) → 已交付(青) → 已分成(绿)
暂停(橙) / 退款(红) 为同级终止状态。

## 奖金阶梯费率

**主体项目:**
- ≤2万: 3%
- 2~5万: 5%
- 5~10万: 7%
- >10万: 10%

**增项（金额较小，费率更高）:**
- ≤5万: 5%
- 5~10万: 7%
- >10万: 10%

## 提成池分配规则

```
提成池 = 项目金额 × 阶梯费率

if 需要UI:
    UI份额 = 提成池 × UI提成比例（5%/7%/10%），从池中先扣除
    开发池 = 提成池 - UI份额
else:
    开发池 = 提成池

开发池按所有开发成员（含负责人）的 share_ratio 分配
```

- **单人无UI项目** → 独享100%
- **多人项目** → 纯按 share_ratio 比例分配，无固定10%负责人加成
- **含UI项目** → UI先按 ui_commission_rate 扣除，剩余开发池按 share_ratio 分
- **开发分成上限** → 无UI: 100%，有UI: 100%-UI比例
- **UI扣除条件** → 项目 needs_ui=true 即扣，不论是否有人承担UI角色
- **未分配UI份额** → 仍计入奖金成本

## 成本计算

```
项目实际耗时 = (实际交付日期 - 开发开始日期) / 30.44 天/月
开发人员工资成本 = 快照工资 × 实际耗时 × 折扣（试用80%/正式100%）
开发人员社保成本 = 快照社保 × 实际耗时（仅正式员工）
UI人员: 只计奖金，不计工资和社保
成本快照: 首次计算时保存，防止涨薪污染历史项目
```

## 项目利润

```
有效收入 = 项目金额 × 35%（内部结算系数）
项目利润 = 有效收入 - 总成本（工资+社保+奖金+提成）
利润率 = 项目利润 / 有效收入
```

## 当月部门利润

```
当月可分款 = 尾款到账(最后一期状态=已到账且到账日期在本月)的项目总额
当月利润 = 当月可分款 × 35% - 尾款项目的工资成本 - 社保成本 - 提成总和
```

## 回款比例模板

动态解析任意付款节奏字符串，每位数字 = 比例×10%，各位之和必须为10。

```
"532"   → 首期款(50%) + 二款(30%) + 尾款(20%)
"4321"  → 首期款(40%) + 二款(30%) + 三款(20%) + 尾款(10%)
"32221" → 首期款(30%) + 二款(20%) + 三款(20%) + 四款(20%) + 尾款(10%)
```

阶段命名: 首期→首期款，中间→二款/三款/四款/五款，最后→尾款。支持任意期数。
回款进度追踪：各阶段实际到账金额≥预期×95%视为达标，达标后提示可推进下一阶段。

## 保底补差

不计入项目成本，独立为月度薪酬结算模块（Phase 3）。
